# Sample Roulette 1.99.7

A macOS sample-discovery and sound-design app with a companion Audio Unit for Ableton Live.

[Open the interactive tour](https://tvsilence.github.io/SampleRoulette/) · [Download the latest release](https://github.com/tvsilence/SampleRoulette/releases/latest)

## What it does

- Browse and randomize your own sample library.
- Build four-sample combinations with tags, locks, mute/solo, pitch, volume, and reverse.
- Discover sounds through Freesound and other free sources.
- Drag a selected sample, a final mix, or four separate stems into Ableton Live.
- Use the Audio Unit for a main mix or four stereo split outputs.
- Generate random tags, save shared states, send optional Dice MIDI note/CC, and process sound with Pure Data effects.

## Installation

1. Download the Apple Silicon `.pkg` from the latest release.
2. Open the installer and launch the standalone app once.
3. If macOS blocks the app, open **System Settings > Privacy & Security** and choose **Open Anyway**.
4. In Ableton Live, rescan Audio Units if Sample Roulette does not appear immediately.

Requires macOS 13 or newer on Apple Silicon.

> This independent build is ad hoc signed and is not Apple-notarized, so macOS may show a security warning.
