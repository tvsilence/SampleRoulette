# Sample Roulette 1.74

A macOS sample discovery and sound design app with an Audio Unit plug-in.

## Download

- [macOS installer (Apple Silicon)](./Sample-Roulette-1.74-macOS-Apple-Silicon.pkg)
- [ZIP archive](./Sample-Roulette-1.74-macOS-Apple-Silicon.zip)

## Installation

Download and open the `.pkg` installer. macOS may show a security warning because this build is distributed without Apple notarization. The installer contains the standalone app and the Audio Unit plug-in.

## Version

Sample Roulette 1.74 (build 174)
